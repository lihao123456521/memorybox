## 原始失败与修复

- 首批车站按键行走停在途中，原批次包含数小时执行停顿；没有未经复现就认定主机或产品根因。新进程、新浏览器重新走过同一路径并完成整个车站动态用例，1.5分钟通过；数值采样也确认该路线连续可通。保留原失败 trace 和报告。
- 领口内搭穿出外衣、腰侧/裙摆被旧横向规则误套用手臂姿态：改用源解剖坐标、关节链距离及区域约束，完整原领片与受控内搭，先同镜头纯色再带材质核对。
- 暂停只冻结路径但骨骼混合仍按帧时间推进：人物接收共享播放时钟，暂停停止混合；新增检查真实关节姿态。重播修订号重置旧混合，避免残留挥手。
- 电视超过有限分支时长后暂停误触重播：只对已结束的有限分支采用播放键重播；新增超过14秒的暂停检查。
- 自身形象高亮误读陪伴者，且总览人物预览镜头未执行：统一高亮/ARIA/打勾状态，独立预览镜头，实测分别保存和刷新。
- 靠墙第三人称过度俯视、总览触物仍远看：优先侧后方避障并保留相机碰撞；物品改用可用近景。最后两项完整复验通过后才构建最终 HTML。

## 边界

- 无 API Key 可完成故事、移动、人物切换、写信和收藏。没有 Lux3D 调用或额度消耗。
- 人物采用 MakeHuman CC0 连续人体/服装与参考引导的参数、局部网格、原UV材质拟合；不是自动图片转3D、摄影测量或真人身份重建。21骨骼为程序动作，没有动捕、手指/口型或布料物理；发型轮廓和服装松量仍与照片参考有差异。
- 电视为原创 Canvas 动画，列车与人物为艺术化场景演绎；真实分支不增加未确认的离开。三个空间不是历史地点的精确复制。
- 自动化采用 Chromium / Edge + SwiftShader，未验证实体移动设备、Safari或物理GPU帧率。
- 收藏属于当前文件及浏览器存储。换路径、浏览器或清除数据可能使旧收藏不可见；私人文字、数据库、密钥不进入公开仓库与离线包。

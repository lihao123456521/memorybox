## 验证边界

- 浏览器自动化使用 Chromium 与 SwiftShader 软件渲染，没有测量物理 GPU 帧率；窄屏视口不是实体手机、iPad 或 Safari 验证。
- 人物是通用虚构陪伴角色，采用真实人体拓扑与皮肤；当前是静态站姿/坐姿和轻微呼吸，未实现完整骨骼表演，视觉尚非摄影级重建。
- 「家的模样」是完整空间旅程；车站和教室是明确标注的叙事预览，共用老屋基础场景。
- 离线收藏属于当前文件和当前浏览器的存储范围；移动文件、换浏览器或清理浏览器数据可能使原收藏不可见，私人文字不会随下载包传播。
- 本轮没有上传私人照片、没有实时大模型生成或 Lux3D 调用，没有消耗 Lux3D 额度。它是可玩的 P0 初版，不宣称满足最终参赛版全部要求。
- pytest 有 Starlette/httpx 弃用提示，不影响上述 19 项通过；未为消除提示擅自升级依赖。

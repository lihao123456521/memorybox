# 老屋室内精修与五空间布局

本轮修改范围为 `frontend/src/scenes/Room.tsx`、`materials.ts` 和 `interior/Details.tsx`。人物、故事控制、全局光照、导航求解和发布由各自模块提供。没有新增在线服务、API Key、付费调用或远程运行依赖。本文的独立精修初验随后又合入精细CC0家具与几何合批，产品最终验收见[验证记录](verification.md)。

## 实际空间与门洞

所有尺寸以米为单位，净高 2.9 m。`Room.tsx` 导出的 `HOME_SCENE_CONFIG` 是以下几何的配置记录，`SCENE_ZONES` 与 `WALK_COLLIDERS` 供外层导航使用。

| 空间 | x 范围 | z 范围 |
|---|---|---|
| 客厅 | -4 至 4 | -3.5 至 3.5 |
| 厨房 | -4 至 4 | -6.8 至 -3.5 |
| 阳台 | 4 至 6.8 | -2.8 至 2.8 |
| 卧室 | -9 至 -4 | -3.5 至 1 |
| 书房 | -9 至 -4 | -7 至 -3.5 |

- 客厅至卧室：x=-4 的墙面，z=-3.2 至 -2.1，门宽 1.1 m。
- 厨房至书房：x=-4 的墙面，z=-5.05 至 -3.95，门宽 1.1 m。
- 卧室至书房：z=-3.5 的墙面，x=-6 至 -4.8，门宽 1.2 m。
- 三个新门洞都有木质门框、压线、门槛和金属嵌条。门洞不放置未经碰撞求解的开启门扇。
- 旧电视 `[3.38,1.15,-2.15]`、布娃娃 `[-3,0.8,-0.5]`、相框 `[0.25,1.4,-3]` 的剧情锚点位置保持不变。

客厅原左外墙现成为卧室隔墙，所以外窗移至客厅前墙；卧室和书房分别有朝西的外窗。厨房后墙增加有实际墙洞的窗。原卧室通路上的绿植移走，原 x=-7 的室外树移至 x=-11.8，避免新增房间内出现树木。

## 建模变化

- 沙发：木质框架、榫接横档、独立扶手栏杆、金属脚垫、分体软座、靠垫、包边缝线和垂落毯穗。保留真实可拾取的布娃娃。
- 窗与窗帘：窗框、压条、轨道、锁扣、固定螺钉、双面玻璃；帘布使用有法线与 UV 的连续褶皱曲面，另有挂环、束带和底缝。
- 卧室：床架与脚、床垫、软包床头、两个带包边的枕头、连续垂坠被面及绗缝线、床尾板、床头柜、台灯、衣柜分体门板和金属拉手、地毯、坐凳。
- 书房：独立书桌、抽屉及金属拉手、五层书柜；书本含纸芯、封面和本地 Canvas 绘制的中文书脊。桌上有纸张叠层、书写垫、铅笔与绿玻璃银行灯。初版简椅随后替换为精细中式扶手椅，见[CC0家具记录](cc0-props-v3.md)。
- 厨房：柜门嵌板、弯曲金属龙头、金属底座、陶瓷储物罐、窗和局部台面灯光。
- 室内细节：墙脚线、顶角线、实心门框多层收边、灯具吊杆与灯罩、纸张和铜件分离材质。

## 材质和来源

室内建筑、软家具几何与 `detailTexture()` 细木纹、棉织物、纸张和地毯纹理为本项目原创程序化资源。集成阶段补入 Poly Haven CC0 电视和中式扶手椅，其余布局保持不变；来源与完整哈希见家具记录。

沿用的摄影 PBR 图像仍是 `docs/room-assets.md` 中记录的 Poly Haven CC0 资源：`wood_floor`、`painted_plaster_wall`、`fabric_pattern_07`，原始链接与哈希仍在 `frontend/public/assets/textures/sources.json`。木家具改用细木纹，避免把地板拼缝重复铺在家具面上。镜面衣柜门是反光 PBR 材质，不宣称实现实时平面镜反射。

所有新增材质在浏览器本地创建；单文件版不需要为这些细节请求额外文件。

## 性能与验证

微小书本、纸层、细框、金属压条使用普通 box，倒角仅保留在靠垫、枕头、床头、主要木作和明显软体上。随后把同材质书芯/封皮几何合并，中文书脊做纹理图集，纸堆按材质合并：相关811个mesh降为54个，保留原三角面、标题、颜色、每本摆放与倾斜。数值对照中顶点/法线误差小于1e-7；该优化不等同于测量GPU帧率。

`Room` 在 Canvas 上发布 `data-home-mesh-count`、`data-home-triangles` 和 `data-home-visible-triangles`。后两者分别是完整老屋几何三角面与相机视锥内几何三角面，独立于后处理最后一个全屏 pass 的 `gl.info` 数值，不是 FPS 承诺。

已使用实际主应用完成客厅至卧室、客厅经厨房至书房的 WASD 通行，验证对应区域变化，浏览器脚本错误数为 0。最后一次实际统计为完整老屋（含人物与室外几何）200,148 三角面、1,962 个网格，书房截图当前视锥内为 11,922 三角面；这不是 FPS 测量。截图与诊断存放在 `artifacts/qa-v3/interiors-*`；TypeScript 检查通过。截图使用隔离的离线演示浏览器，不访问或修改用户已有回忆。首次检查发现床头背面朝向入口，已调整为床头靠墙、入口看床尾，并重新拍摄。

上述200,148三角面、1,962网格是合批与家具替换前的独立子阶段记录。最终场景与各故事、离线包的集成结果以验证记录为准。

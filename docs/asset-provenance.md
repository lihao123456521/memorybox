# 素材来源与真实性

运行时逐项清单以 `frontend/public/assets/manifest.json` 为准。所有模型文件地址为空时均表示程序化网格，不代表存在尚未导出的 GLB。

| 资源 | 当前来源 | 应用方式 |
|---|---|---|
| 机械八音盒、独立盒盖与内部机芯 | 项目原创 Three.js 几何体 | 铰链开盖、镜面反射、销钉圆筒与齿轮转动，开场穿越与收藏状态变化 |
| 五房间老屋、车站/列车、教室/走廊 | 项目原创精细几何与本地PBR | 三套可通行的独立世界 |
| 精细电视与中式扶手椅 | Poly Haven CC0 1K GLB，内嵌 diffuse/normal/ARM | 见[模型记录](cc0-props-v3.md)；电视仍使用独立射线拾取与剧情锚点 |
| 红色布娃娃 | 项目原创程序化建模 | 独立网格、剧情锚点和归来纪念物 |
| 家庭相框 | 项目原创程序化建模 | 独立网格，表面应用合影纹理 |
| 四类成年陪伴人物 | MakeHuman CC0 人体、形态、皮肤、衣物、发型与五官；项目原创拟合和转换逻辑 | 青年男性、长者男性、青年女性、长者女性；见[人物升级](character-assets-v3.md)，不是真实人物复刻 |
| 木地板、墙面、织物 PBR | Poly Haven CC0，文件已随项目保存 | 见[房间记录](room-assets.md)，运行无需网络 |
| Lebombo 1K HDR | Poly Haven CC0，Greg Zaal | 仅用于室内照明与反射，不作为二维背景；来源与哈希见 environments/source.json |
| 信封与收藏物 | 项目原创程序化建模 | 现实木盒中的旅程结果 |
| 家庭合影 `family-photo.png` | Agent 使用 OpenAI 内置 `image_gen` 生成 | 仅用作相框中的 2D 照片纹理 |
| 木纹和备用合影 | 项目原创 Canvas 纹理 | 图片不可用时继续显示相框和房间 |
| 交互音效 | 项目原创 Web Audio 合成 | 经用户点击开启，可关闭 |

合影描述为虚构的中国奶奶、孩子和红色布娃娃，2005 年夏天庭院，暖色绘本风，无文字和水印。摘要提示词保存在 manifest；完整生成记录由主实现留存。未上传或使用用户私人照片，没有下载来源不明的商业模型、配乐或字体。字体使用系统可用字体链。

3D 空间始终由 WebGL 渲染的网格、材质、相机和灯光构成；合影和截图均不代替可探索场景。

**Lux3D 未接入。** 所有 Lux3D 任务 ID 为 `null`，没有本轮生成任务、调用耗额或真实供应商 GLB 记录，不宣称此 P0 原型已满足最终参赛版的技术栈要求。

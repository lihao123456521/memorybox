合影描述为虚构的中国奶奶、孩子和红色布娃娃，2005 年夏天庭院，暖色绘本风，无文字和水印。摘要提示词保存在 manifest；完整生成记录由主实现留存。四套人物参考是独立生成的虚构设定，不表示用户逐张确认，也不把生成图的来源混称为上游 MakeHuman CC0。未上传或使用用户私人照片，没有下载来源不明的商业模型、配乐或字体。字体使用系统可用字体链。

3D 空间始终由 WebGL 渲染的网格、材质、相机和灯光构成；合影和截图均不代替可探索场景。人物参考图只在构建时引导参数与原 UV 拟合，完整 PNG 不作为运行时平面人物；局部烘焙不等于校准的多视角摄影测量或精确身份重建。

第一 / 第三人称切换、玩家自身形象和陪伴角色是本项目应用逻辑，不添加新第三方素材来源。浏览器分别保存选择；真实分支仍受已确认事实约束，预定场景动作不构成真实历史证据。运行时不需要图像生成 API、网络或 API Key。

**Lux3D 未接入。** 所有 Lux3D 任务 ID 为 `null`，没有本轮生成任务、调用耗额或真实供应商 GLB 记录，不宣称 v0.4 原型已满足最终参赛版的 Lux3D 技术栈要求。正式下载包和哈希须在实际构建、发布与匿名下载校验后记录，不能从来源表推定。

# 本地演示顺序

1. 双击根目录 `index.html`（或开发时打开 `http://127.0.0.1:5173`），观察机械八音盒，拖动换角度；点击打开，检查盒盖、镜面和内部圆筒齿轮。
2. 进入「家的模样」，使用 2005 年夏天的示例。可更改人物和真实选择后检查确认卡。
3. 观察镜头推进与虚化穿越。进入老屋后用 WASD / 方向键行走、拖动环顾，通过真实门洞进入厨房、阳台、卧室与书房；切换四类精细人物。回客厅触摸电视、红布娃娃和家庭相框；也可切房间总览寻找物件。
4. 集齐三件记忆后先体验「重温真实路线」，留意告别、暮色与门口。
5. 重新选择「多留一个下午」，检查醒目的想象标识、不同对话与环境事件。
6. 写给奶奶或那时自己的信，保存并返回现实木盒；重新打开信件验证内容。
7. 从头再体验或刷新，检查已保存的收藏仍在。演示结束可在收藏中删除测试回忆。

随后可选择独立的火车站，从候车大厅走过站台进入车厢、沿中间通道前进；或进入教室和走廊。它们各自有三个不同的故事物件、分支与写信闭环。

叙事节奏由体验者控制，没有五分钟强制倒计时。三套空间是艺术化模板，不声称对真实地点做精确历史复原。

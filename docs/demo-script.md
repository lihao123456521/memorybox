# 本地演示顺序 · v0.4.0

这是 v0.4.0 的演示顺序；实际测试批次和边界见 [验证记录](verification.md)。根目录 HTML 已按本轮源码重建，v0.3 历史包不包含新增功能。

1. 双击已重建的根目录 `index.html`（开发时打开 `http://127.0.0.1:5173`），拖动观察珠贝胡桃木八音盒；点击打开，观察独立盒盖、椭圆镜面、绒布托盘、机芯观察窗、圆筒齿轮与旋转水晶玫瑰。
2. 进入「家的模样」，使用 2005 年夏天的示例。可更改人物和真实选择后检查确认卡。
3. 观察花瓣时空门展开、曲线镜头推进和加载遮罩。进入老屋后先以第一人称 WASD / 方向键行走、拖动环顾，穿过门洞进入厨房、阳台、卧室和书房；再切第三人称与总览，留意玩家位置是否保留、跟随镜头是否被墙或家具挡住。
4. 在人物设置分别选择“陪伴角色”和“我的形象 · 第三人称”，检查两者互不替换及当前选择反馈。关闭面板后行走，观察完整人物的步态、脚底、衣领与裙摆；21 骨骼程序动作不等于完整动作捕捉表演。
5. 回客厅触摸电视，观察原创节目画面确实随时间变化；用暂停、播放、重播控制它，再探索红布娃娃和相框。集齐三件物品后体验「重温真实路线」，观察字幕段与人物转身、沿通道行走、停步和挥手；中途暂停与重播，检查动作是否随同一时钟停住和重置。
6. 重新选择「多留一个下午」，检查想象标识、不同对话与场景动作。再用一个不包含离开事实的自定义真实选择检查真实路线，应维持中性陪伴，不添加未经确认的离开。
7. 写给奶奶或那时自己的信，保存并返回现实八音盒；重新打开信件检查内容。
8. 从头再体验或刷新，检查收藏、两类人物选择与视角偏好。演示结束可在收藏中删除测试回忆。

随后选择独立车站，从候车大厅走过站台进入车厢、沿中间通道前进。进入相应告别分支，观察陪伴者走到黄线内侧、滑门关闭、信号变化、车轮随车体驶离转动；暂停 / 重播后应共同停住 / 回到起点。教室则检查中央过道、后排通路与门边挥手。三套空间各有三件不同故事物件、分支与写信闭环。

叙事节奏由体验者控制，没有五分钟强制倒计时。三套空间是艺术化模板，不声称对真实地点做精确历史复原。

人物参考图先于本轮拟合生成，实际人物沿用 MakeHuman CC0 网格与原 UV，再做参数 / 几何 / 材质处理。多视角设定图不等于自动 AI 重建结果；演示应展示可交互的真实三维人物和连续动作，而不能用参考图或单帧截图替代。
